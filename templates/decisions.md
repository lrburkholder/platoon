# Decisions and AI contributions

Append meaningful entries only after the human confirms the decision, reasoning, and attribution. Keep corrections as new entries. Record material generated code or tests, human modifications, and verified results where relevant. Use a step ID or file reference when it helps reconstruct the work. Keep secrets and prohibited assignment material out of the log.

Copy this entry when needed.

```markdown

- Decision: [what was chosen or the bounded step approved]
- Why: [human-confirmed reason]
- Alternatives: [rejected options, if relevant]
- Origin: [human / AI proposed, accepted / AI proposed, modified]
- AI contribution: [design / tests / implementation / review / documentation / none, with a short description]
- Evidence: [observed command and result, file reference, or pending check]
```
